보카3000 개인정보처리방침

보카3000은 어떤 개인정보도 수집·저장·전송하지 않습니다.

1. 수집하는 정보

없습니다. 본 앱은 회원가입·로그인이 없으며, 서버와 통신하지 않는 완전 오프라인 앱입니다. 이름, 이메일, 위치, 광고 식별자, 기기 정보를 포함한 어떠한 개인정보도 수집하지 않습니다.

2. 기기에 저장되는 데이터

학습 진도, 문제 풀이 기록, 설정(스킨·글자 크기 등)은 사용자 기기 내부 저장소에만 저장됩니다. 이 데이터는 외부로 전송되지 않으며, 개발자를 포함한 누구도 접근할 수 없습니다. 앱을 삭제하면 함께 삭제됩니다.

3. 데이터 백업

설정 화면의 '데이터 내보내기'는 학습 기록을 JSON 파일로 만들어 사용자가 직접 선택한 위치에 저장하는 기능입니다. 이 과정에서도 데이터는 개발자나 제3자에게 전송되지 않습니다.

4. 음성 재생

단어·예문 발음은 기기에 내장된 문자-음성 변환(TTS) 기능을 사용하며, 읽어 줄 텍스트가 외부 서버로 전송되지 않습니다.

5. 광고·분석 도구

광고, 추적기, 분석 도구(애널리틱스)를 일절 사용하지 않습니다.

6. 아동 개인정보

본 앱은 초·중·고 학생을 포함한 모든 연령이 사용할 수 있으며, 아동을 포함한 어떤 사용자의 개인정보도 수집하지 않습니다.

7. 문의

개인정보처리방침에 대한 문의는 GitHub 저장소 이슈 또는 Google Play 스토어에 표시된 개발자 이메일로 연락해 주세요.

8. 방침 변경

방침이 변경되는 경우 이 페이지를 통해 고지합니다.
