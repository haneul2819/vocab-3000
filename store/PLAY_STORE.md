📚 교육부가 고시한 초·중·고 필수 영단어 3,000개를 한 앱에서!

보카3000은 교육부 고시 제2022-33호 영어과 교육과정 '기본 어휘 3,000'을
그대로 담은 영단어 학습 앱입니다. 회원가입도, 인터넷도, 광고도 없습니다.

✨ 이런 분께 추천해요
• 초등·중등·고등 교과서 필수 단어를 체계적으로 외우고 싶은 학생
• 아이에게 광고 없는 안전한 학습 앱을 주고 싶은 학부모
• 기초 영단어를 다시 다지고 싶은 성인

🃏 암기 카드
• 단어·발음기호·뜻·예문 2개·파생어를 한 카드에
• 좌우로 넘기며 학습, 모름/헷갈림/앎 3단계 판정
• 카드를 길게 누르면 예쁜 단어 이미지로 저장·공유
• 원어민 발음 듣기(기기 TTS), 듣기 모드로 흘려듣기 반복

📝 문제집 · 오늘의 테스트
• 단어→뜻, 뜻→단어, 철자 입력, 듣고 쓰기, 예문 빈칸, 파생어 6가지 유형
• 10/20/30문제 선택, 매일 50문제 '오늘의 테스트'로 하루 마무리
• 오답은 자동으로 오답 노트에 모이고, 3번 연속 맞히면 졸업

🔁 과학적인 반복 복습
• 헷갈린 단어는 1일 → 3일 → 7일 → 30일 간격으로 다시 등장 (간격 반복)
• 30문항 진단 테스트로 내 수준에 맞는 시작 위치 추천

📖 문법 예문
• 교육과정 문법 범주별 예문 모음, 파트별 전체 듣기·반복 듣기
• 빈칸 채우기·어순 배열 문제로 문법 감각까지

📊 학습 통계
• 학습·테스트 진도, 연속 학습일, 날짜별 테스트 점수 그래프

## 4. 데이터 보안(Data safety) 섹션 답변

| 질문 | 답변 |
|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하나요? | **아니요** |
| 데이터가 전송 중에 암호화되나요? | (수집 안 함 → 해당 없음) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | (수집 안 함 → 해당 없음) |

→ '데이터를 수집하지 않음'으로 표시됩니다. 학습 기록은 기기 안에만 저장되고
개발자에게 전송되지 않으므로 Play 정책상 '수집'에 해당하지 않습니다.

## 8. 제출 순서 (Play Console)

1. https://play.google.com/console 에서 개발자 계정 등록 ($25, 1회)
   — 개인 계정이면 신분증 확인 + 기기 2단계 인증 필요할 수 있음
2. **앱 만들기**: 이름 `보카3000 - 초중고 필수 영단어`, 기본 언어 한국어,
   앱, 무료 선택
3. 좌측 **앱 콘텐츠** 메뉴에서 위 3–7번 항목 순서대로 입력
4. **스토어 등록정보**: 위 1번 문구 + 그래픽 자산 업로드
5. **프로덕션 → 새 버전 만들기**: GitHub Actions 아티팩트의
   `app-release.aab` 업로드
   - "Google에서 앱 서명 키 관리" 동의(권장) — 업로드 키는 우리 키 유지
6. 출시 노트 작성 (예: `첫 출시 — 교육부 기본 어휘 3,000 단어장`)
7. **검토를 위해 제출** → 심사는 보통 수일 이내

## 9. 업데이트 배포 방법

1. 코드 수정 → main 머지
2. `android/app/build.gradle`의 `versionCode` +1 (예: 1 → 2),
   `versionName` 갱신 (예: "1.1")
3. Actions → Build Android App 실행 → 새 AAB를 프로덕션 새 버전으로 업로드
